# Zaira Shahid — Portfolio

Personal portfolio for Zaira Shahid — AI Automation Engineer, Full-Stack Developer, and GTM Engineer.

Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

- `app/` — routes, layout, global styles, metadata
- `components/layout/` — navbar, mobile nav, footer
- `components/sections/` — page sections (hero, about, projects, etc.)
- `components/ui/` — reusable UI primitives
- `components/motion/` — animation/reveal wrappers
- `content/` — typed content (profile, projects, experience, skills) — edit these to update site content without touching layout code
- `public/` — images, project media, resume, favicon
- `docs/PORTFOLIO_SPEC.md` — full build specification (source of truth)

## Scripts

```bash
npm run dev     # start dev server
npm run build   # production build
npm run lint    # lint
```
